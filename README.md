# 🪙 Coin Collector Game

A simple and fun coin collection game where players control a character, move around the game environment, and collect coins to increase their score. The main goal is to collect as many coins as possible while enjoying a simple and interactive gaming experience.

## 🎮 About the Game

This project was developed to explore basic game development concepts, including player movement, collision detection, score tracking, and interactive gameplay. It provides a simple gaming experience while demonstrating how fundamental programming concepts can be used to create an engaging game.

## ✨ Features

- **Player Movement:** Control the player character using keyboard inputs.
- **Coin Collection:** Collect coins placed throughout the game environment.
- **Score Tracking:** Earn points for every coin collected.
- **Collision Detection:** Detect interactions between the player and coins.
- **Interactive Gameplay:** Enjoy a simple and engaging game experience.
